
# ImobGestor

Sistema de gestão imobiliária desenvolvido com Java
e Spring Boot.

## Tecnologias

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Flyway
- Docker
- Maven

## Funcionalidades

- [ ] Gestão de pessoas
- [ ] Gestão de imóveis
- [ ] Gestão de contratos
- [ ] Gestão financeira
- [ ] Gestão tributária
- [ ] Integrações fiscais

## Executar o projeto

### 1. Iniciar o banco

docker compose up -d

### 2. Executar a aplicação

./mvnw spring-boot:run

No Windows:

mvnw.cmd spring-boot:run
